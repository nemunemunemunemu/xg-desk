How this works

Only parameters you touch are managed (bright). Dimmed rows are left alone, so whatever Ableton or the MU50 has stays put. Use × to stop managing a parameter (it also sends the XG default where one is known).

Ableton routing: Ableton can't send SysEx from clips, so put this app in the middle. Install a virtual port (e.g. loopMIDI), send Ableton's MIDI tracks to it, pick it as MIDI In here, and pick your interface to the MU50 as MIDI Out. Thru forwards your notes; the setup gets sent alongside.

Auto-recall: turn on Sync for the loopMIDI output in Ableton's MIDI preferences and enable “Resend setup on MIDI Start”. Leave an empty bar at the start of the song so the reset finishes before notes play.

Per-track effects: the MU50 has one Reverb, one Chorus and one Variation block. Each part sets its own send levels, filter, envelope and vibrato. The Variation block can be made an insertion effect on one part (e.g. distortion on just the guitar).

Note: CC7/10/91/93/94 sent from Ableton will override Volume/Pan/Sends set here.
